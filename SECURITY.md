# Security Policy

Please do not report security issues publicly.

Email security reports to:

```text
vikeshcodes@gmail.com
```

Do not include real access tokens, refresh tokens, Google client secrets, database passwords, or private stream URLs in public issues.

## Supported Versions

The latest `main` branch is supported for security fixes during early development.

## Security Topics

Important areas:

- OAuth tokens
- YouTube API credentials
- Local database
- Admin access
- OBS browser source URLs
- WebSocket event broadcasting

## Reporting

Include:

- A clear description
- Reproduction steps
- Impact
- Affected files or endpoints
- Suggested fix if known

Please give maintainers reasonable time to respond before public disclosure.
