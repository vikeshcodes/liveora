# Governance

Vikesh Codes Creator OS is originally created and owned by VikeshCodes.

Project direction is controlled by VikeshCodes. Community contributions are welcome, and maintainers review issues and pull requests in good faith.

Not every contribution will be accepted. Final decisions about roadmap, branding, releases, and official distribution belong to VikeshCodes.

Contributors can suggest and submit:

- Features
- Bug fixes
- Documentation
- Themes
- Integrations
- Performance improvements
- Developer experience improvements

Only VikeshCodes maintainers can decide what becomes part of the official project.
